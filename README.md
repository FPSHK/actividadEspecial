# Hardware-Care - Landing Page

Landing page para Hardware-Care, una organización sin fines de lucro que repara dispositivos electrónicos a nivel de hardware. Hecho con HTML, CSS Grid y Flexbox, con diseño responsivo.

## Archivos
- `index.html` - página principal
- `suscribir.html` - página del formulario de suscripción (para móvil)
- `style.css` - todos los estilos

## Qué incluye
- Header, Acerca de Nosotros, Cómo Ayudar (con botones de donación), Testimonios, Imágenes y Footer, organizados con CSS Grid.
- Testimonios e imágenes en fila con Flexbox.
- Formulario de suscripción (nombre, correo, botón) en fila.
- Responsivo: en pantallas pequeñas el header reduce texto, testimonios e imágenes pasan a una columna, y el formulario se reemplaza por un botón que lleva a `suscribir.html` (con su propio botón de regreso).

## Cómo verla
Abre `index.html` en el navegador. Asegúrate de tener las imágenes (`imagen01.jpg`, `imagen02.jpg`, `imagen03.jpg`) en la misma carpeta.
